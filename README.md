# Poker Hand Trainer

フロップ/ターン/リバーで自分の手札の強さ（上に何組、下に何組、勝率%）を
一瞬で判断できるようになるための練習用 Web アプリ。

## 機能

- **カード選択 UI**: 自分の 2 枚 + ボード 3〜5 枚をクリックで指定
- **手の強さパネル**: 役名 / 現在の勝率 / ショウダウン勝率 / 上下のコンボ数
- **13×13 ハンドマトリクス**: 相手の取りうる全ハンドクラスを色分け
- **マーク機能**: 「自分でクリックして開示」モードで自己テスト
- **カテゴリ絞り込み**: フラッシュ・ストレートなど役別に表示
- **コンボ詳細**: マトリクスのセルをクリックで個別コンボを表示

## ローカルで動かす

ES Modules を使っているため、`file://` 直接ではなく簡易 HTTP サーバが必要です。

```bash
# Python が入っていれば
python -m http.server 8000
# その後 http://localhost:8000 を開く
```

または VS Code の Live Server 拡張など。

## エンジンのテスト

```bash
node tests/eval.mjs   # 評価器の正当性チェック
node tests/perf.mjs   # ベンチマーク
```

## 計算方法

- **現在の勝率 / 上下のコンボ数**: 相手の取りうる 2 枚の全列挙（フロップで 1081 通り）
- **ショウダウン勝率**:
  - リバー: 厳密 = 現在勝率
  - ターン: 厳密列挙（C(46,2) × 44 ≈ 45k）
  - フロップ: Monte Carlo 8000 サンプル

## 役の優先順位

ストレートフラッシュ > フォーカード > フルハウス > フラッシュ > ストレート >
スリーカード > ツーペア > ワンペア > ハイカード
